## 💡 About

NegiluAI is a smart platform that helps farmers and FPOs manage, sell, and move agricultural produce more efficiently.

## 🚀 Key Features

- Direct Farmer-to-Buyer Marketplace
- AI-Based Price & Demand Prediction
- Early Oversupply Alerts
- Real-Time Inventory Management
- Smart Route Optimization
- Freshness-Focused Delivery

## 🛠️ Technology

- React.js
- FastAPI
- PostgreSQL + PostGIS
- Prophet & XGBoost
- Google OR-Tools
- Docker & Cloud
